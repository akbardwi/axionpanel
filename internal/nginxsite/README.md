# nginxsite

`internal/nginxsite` provisions **initial static sites**, not user accounts,
uploads, PHP, TLS, or a general file manager. It is a vertical slice: content
is a single root-owned initial index, and there is deliberately **no per-user
runtime or file-management API** — that narrow exception is documented here
instead of faking system users.

## API

```go
type Config struct {
    StateDir, ContentDir, ConfigDir, NginxBinary, NginxConfig, Prefix string
    Listen      string         // explicit trusted startup bind, "ip:port"
    Reloader    func(context.Context) error // optional isolated harness reload
    Runner      Runner         // optional; default is absolute exec, no shell
}

func New(c Config) (*Manager, error)
func (m *Manager) Close() error
func (m *Manager) Plan(domain string) (Plan, error)    // no mutation
func (m *Manager) Apply(ctx context.Context, operationID, domain string) (Result, error)
func (m *Manager) Remove(ctx context.Context, operationID, domain string) (Result, error)
func (m *Manager) Status(ctx context.Context, domain string) (Result, error)
```

- **Domains**: lowercase ASCII DNS only; no wildcards, no IP literals.
- **OperationIDs**: 32 hex chars, generated by the panel via crypto/rand.
- **Listeners/commands**: none are accepted per request. The bind address
  and nginx binary/config are fixed at startup; `Runner` executes an
  absolute executable with fixed argv and **no shell**.

## Security model

- Roots must be pre-created, **root-owned (uid 0), non-world/group-writable**,
  with non-writable ancestors; `StateDir` must be `0700`. `New` pins them
  via `openat(O_NOFOLLOW)` traversal and refuses symlinked ancestors.
- Managed files (configs, journals, markers) must be regular, unlinked
  (nlink==1), root-owned, `0600`/`0644`, no setuid/setgid. Symlinks and
  hardlinks are rejected.
- Content is only ever created as `ContentDir/domain/public/index.html`
  plus a private `.axion-managed` marker; `Remove` deletes the config and
  **retains** the content directory (never recursive delete). Re-applying
  to a retained site fails with `ErrRetainedContent` — silent adoption is
  impossible.
- The rendered vhost denies dotfiles and common dynamic extensions
  (`*.php`, `*.phtml`, `*.phar`, `*.cgi`, `*.pl`, `*.py`, ...), so PHP
  source is never exposed or interpreted.
- Every mutation: `nginx -t` on the preexisting config **before** writes,
  atomic publish (tmp + renameat), validate + reload; on failure the exact
  prior vhost (or its absence) is restored and re-validated.
- A durable private journal is written **before** mutation (pending phase,
  digest of action/domain/listen, result, error class). Repeated identical
  request → cached result; changed request under same ID →
  `ErrOperationConflict`; a `pending` record found on restart blocks that
  operation and every new mutation with `ErrInterruptedOp` (manual
  reconcile, never auto-replay).

## Cross-process safety

`flock` on a private lock file in `StateDir` serializes instances and
processes; an in-process mutex serializes calls on one manager.

## Tests

```
go test ./internal/nginxsite            # all suites, real nginx in isolated prefix
go test -race ./internal/nginxsite
go test -count=2 ./internal/nginxsite   # idempotent repeat
```

`TestRealNginxLifecycle` launches real nginx on a loopback high port in an
isolated scratch prefix (never touching live config) and asserts the served
page. `TestBoundaryAndRecovery/preexisting` additionally runs the real
binary to confirm a broken preexisting config is refused.
